# ark-filecheck

*Updated as of 01/05/26*

# How to use
Either install python and run the .py file (some packages may need installing), or run the .exe (defender WILL flag it) and enjoy!
Any other file paths / registry things I am missing lmk! 

Ensure any cheat configs are saved to a safe location before running.
The file automatically deletes after one use, so should be undetectable.


# v2
Version 2 adds the option for a harsher scan, deleting all files related to cheats on that computer.
Also wipes UserAssist registry, so after running cheats won't be detectable by things such as userassist-too.exe (commonly used for filechecks)
